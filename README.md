# SCloudMusicBot

Telegram-бот для поиска, распознавания и загрузки музыки из SoundCloud, Spotify и YouTube. В проект входят бот, веб-админка, аналитика продукта и платежей, поддержка пользователей, рассылки и управляемые рекламные кампании.

## Возможности

- загрузка отдельных треков и плейлистов;
- тарифы Free, Plus, Pro и Unlimited с оплатой Telegram Stars и ручной активацией;
- централизованные дневные лимиты с индивидуальными исключениями;
- админ-панель: пользователи, тексты, настройки, рассылки, поддержка, аналитика и реклама;
- рекламные кампании с медиа, cooldown, ограничением показов, архивом и полной событийной статистикой;
- PostgreSQL/Supabase как основное хранилище и Redis для координации экземпляров и сессий.

## Стек

Node.js 18+, Telegraf 4.16, Express 4.19, EJS 3.1, PostgreSQL (`pg` 8.21), Supabase JS 2.39, Redis/ioredis, yt-dlp и FFmpeg.

## Быстрый запуск

```bash
npm ci
cp env.example .env
npm test
npm start
```

Заполните `.env` собственными значениями. Минимально нужны `BOT_TOKEN`, `DATABASE_URL` и идентификатор администратора; production дополнительно требует настройки webhook, сессий и доступа к админке. Полный список и порядок выпуска описаны в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).

Миграции из `migrations/` применяются вручную и строго по порядку. Скрипты не применяют миграции к Supabase при обычном запуске приложения.

## Структура

- `bot.js` — Telegram-сценарии и платежи;
- `index.js` — запуск приложения, админ-маршруты и Dashboard;
- `services/` — доменная логика;
- `views/` и `public/` — интерфейс админки;
- `migrations/` — версионируемые SQL-изменения;
- `test/` — автоматические тесты;
- `integration/` и `scripts/` — интеграционные и эксплуатационные проверки;
- `hf-worker/` — опциональный удалённый обработчик загрузок.

## Дневные лимиты

Эффективный лимит вычисляется единым сервисом:

1. `users.daily_limit_override`, если он задан;
2. активный `users.tariff_code`;
3. актуальное значение `app_settings.daily_limit_<tariff>`;
4. программный fallback только при недоступности или некорректности настройки.

`users.premium_limit` сохранён для совместимости и классификации старых записей. Его числовое значение не перекрывает глобальную настройку тарифа. Удаление `daily_limit_override` сразу возвращает пользователя к актуальному глобальному лимиту.

## Безопасность

Секреты и `.env` не входят в документацию и не должны попадать в Git. Медиа рекламных кампаний хранится в приватном bucket `ad-campaign-media`; загрузка и предпросмотр доступны только через защищённые административные маршруты. Маршрут `/support/file/:messageId` также закрыт `requireAuth`.
